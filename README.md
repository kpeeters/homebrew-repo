Homebrew tap
============

Homebrew formulae for software written by Kasper Peeters.


Cadabra2
--------

Computer algebra system. For more information, see
https://cadabra.science/, where documentation and tutorials can be
found. Install with

    brew tap kpeeters/repo
	brew install cadabra2
	
This automatically installs cadabra's python package dependencies such
as sympy and matplotlib into a separate virtual environment.


GainDrive (server)
------------------

Subsonic-compatible audio/video server. For more information, see
https://www.gaindrive.org/, where documentation and client apps can be
found. Install with

    brew tap kpeeters/repo
	brew install gaindrive-server
	
Then go to the website above and learn how to configure it.
